# SmartStaff Clock

שעון נוכחות לעובדים: סורקים ברקוד באתר, לוחצים כניסה או יציאה, והשעות נרשמות בגיליון גוגל.

## מה יש כאן

| קובץ | מה הוא |
|---|---|
| `index.html` | מסך העובד (עברית, אנגלית, רוסית, סינהלית) |
| `admin.html` | מסך המנהל: מי במשמרת, סיכום חודשי, עריכת משמרות, אישור החלפת נייד |
| `apps-script/Code.gs` | צד השרת, רץ ב-Google Apps Script שמחובר לגיליון |
| `tests/` | בדיקות אוטומטיות שמריצות את הקוד האמיתי מול גיליון מדומה |

## כתובות

- עובדים: `/?s=cargo` (הקוד אחרי `s=` הוא העמודה Site code בלשונית Settings)
- מנהל: `/admin.html`

שני הדפים פונים לכתובת ה-Web App של Apps Script, שכתובה בראש הסקריפט של כל דף (`FALLBACK_API`).
אם יוצרים פריסה חדשה ב-Apps Script הכתובת משתנה וצריך לעדכן אותה בשני הדפים.
כדי שהיא לא תשתנה: פריסה ← ניהול פריסות ← עיפרון ← גרסה חדשה.

## עדכון צד השרת

להדביק את `apps-script/Code.gs` בעורך Apps Script של הגיליון, ואז לפרוס גרסה חדשה כמו למעלה.
קוד המנהל לא נמצא במאגר. הוא נשמר בגיליון, בלשונית Settings, תא J2.

## בדיקות

```
node tests/server.test.js
node tests/browser.test.js   # דורש playwright
```
